# Чёрное небо

Стратегия о лесном пожаре в Красноярском крае. Игрок — огонь: он не управляет
юнитами, а покупает эволюции, меняющие константы симуляции. Цель — сжечь больше,
чем в рекордном 2019 году, до прихода осеннего циклона.

Референс — Plague Inc., но карта здесь не декорация: граф соседства из 39
муниципальных округов построен по реальной геометрии OpenStreetMap.

## Запуск

Нужен Node.js 22.12+ (или 20.19+). Карта использует WebGL 2:
в браузере должно быть включено аппаратное ускорение.

```bash
npm install
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Локальный сервер разработки |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm test` | Тесты данных, симуляции, сохранений и таблицы лидеров |
| `npm run test:e2e` | Браузерные сценарии, мобильная раскладка и проверка карты |
| `npm run check` | Тесты, проверка типов и production-сборка |
| `npm run balance -- 200 --dist` | Headless-прогон: форма распределения исходов |

Для браузерных проверок один раз выполните `npx playwright install chromium`.
Если Chromium не установлен, можно использовать установленный Edge:
в PowerShell задайте `$env:PLAYWRIGHT_CHANNEL = 'msedge'`, затем запустите
`npm run test:e2e`. Скриншоты и отчёт лежат в `artifacts/`.

## Партия

Автосохранение хранится в текущем браузере: каждые игровые сутки, после
покупки или действия, при открытии меню и уходе со страницы. «Продолжить
сезон» восстанавливает погоду, случайную последовательность, покупки и
фронт на паузе. Начало нового сезона требует подтверждения замены сохранения.
Рекорд завершённых партий сохраняется отдельно. Очистка данных браузера
удаляет сохранение и рекорд; приватный режим может ограничивать хранение.

Меню и дерево эволюций останавливают время. При переключении вкладки игра
остаётся на паузе до явного продолжения. Скорости: 1×, 2× и 5×. Пробел
переключает паузу, E открывает эволюции, Escape закрывает панель или меню.
Округ можно выбрать на карте или в списке; соседние округа в сводке тоже
доступны для перехода. Все основные действия доступны с клавиатуры.

Спутниковые снимки Esri загружаются через интернет. При их недоступности
игра использует локальную геометрию районов и рек; игровой процесс
продолжает работать. Это резервная подложка, а не полная офлайн-установка.

## Таблица лидеров

Общая таблица результатов хранится в Supabase: GitHub Pages отдаёт только
статичные файлы. Настройка выполняется один раз:

1. Создать проект на [supabase.com](https://supabase.com) (бесплатный тариф).
2. В SQL Editor выполнить `supabase/leaderboard.sql` — таблица, права доступа
   (только чтение и добавление) и ограничение частоты записей.
3. Взять адрес проекта и публичный ключ (Project Settings → API) и записать их
   в файл `.env` по образцу `.env.example`.

Публичный ключ попадает в код страницы — так задумано в Supabase: права
определяют политики RLS. Без переменных игра работает, а таблица скрыта.
Результат считается в браузере игрока, поэтому ограничения таблицы отсекают
только невозможные значения, а не правдоподобную подделку.

## Проверка Перед Выпуском

Исправлены зависающие затухшие очаги, проверки покупки эволюций,
летние шквалы, верховой пожар в хвойных районах и учёт встречного отжига.
Есть регрессии для завершения сезона и неизменности законченной партии.
Проверка сохранений сравнивает продолжение симуляции с исходной партией.

Автоматический прогон 800 партий подтвердил влияние стратегии на результат.
Окончательная настройка сложности требует игровых сессий с людьми:
раннее поражение всё ещё возможно, а погода влияет на исход. До публичного
релиза также стоит проверить игру на целевых физических телефонах и
определиться со звуком, обучением и платформой распространения.

## Устройство

```
src/sim/    симуляция, чистый TypeScript без обращений к DOM
src/map/    MapLibre: слои, цветовая шкала
src/ui/     экраны и HUD
tools/      подготовка данных (Python) и прогонщик баланса (TypeScript)
data/       производные данные, читаются игрой
```

Симуляция отделена от рендера не ради чистоты кода, а ради `tools/balance.ts`:
тот же код гоняет тысячу партий без браузера за 11 секунд, и константы
подбираются по распределению исходов, а не на глаз.

## Данные

Всё из OpenStreetMap, готовится один раз скриптами `tools/step1..step4`.
Сырые выгрузки (`data/raw/`) не хранятся в репозитории — они воспроизводятся:

```bash
python tools/step1_list.py       # список округов
python tools/step2_geometry.py   # геометрия границ, возобновляемая загрузка
python tools/step3_build.py      # сшивка колец, граф соседства, упрощение
python tools/step4_attributes.py # население, дороги, реки, аэродромы
```

Граф соседства строится **пересечением множеств way id**: соседние
административные отношения в OSM ссылаются на один и тот же way вдоль общей
границы, поэтому длина общей границы считается точно, без геометрических
операций.

Лесистость и тип горючего — курируемая таблица в `step4_attributes.py`, а не
зональная статистика по ESA WorldCover: последняя требует десятков гигабайт
тайлов 10 м на площадь края. Таблица помечена в коде и заменяется без изменений
в остальном пайплайне.

## Публикация

`.github/workflows/deploy.yml` собирает и публикует на GitHub Pages при пуше
в `main`. В настройках репозитория нужно включить Pages с источником
**GitHub Actions**.
